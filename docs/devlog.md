# 鲸汐提炼器 · 消息重点提取

粘一段乱糟糟的长消息（群聊 / 邮件 / 会议纪要 / 文章），一键变成四块卡片：**一句话结论 / 关键信息 / 待办事项 / 风险与分歧**。

## 怎么用

1. 双击 `index.html`（Chrome / Edge，不需要安装、不需要服务器）。
2. 右上角 **钥匙图标** → 粘一个 DeepSeek API Key（`sk-` 开头）→ 保存。只存在本机浏览器的 localStorage 里，关掉再开还在。
3. 把文本粘进大框，选类型（聊天记录 / 邮件 / 会议纪要 / 通用）。
4. 点「一键提炼」，或按 `Ctrl / ⌘ + Enter`。
5. 每条要点下面的「▸ 原文」点开，就是它依据的原文摘句，防止模型编造。
6. 卡片右下角「复制卡片」→ 已是纯文本（带小标题、编号），直接粘微信或 Word。
7. 提炼过的会自动进左侧「历史」（最近 20 条），点一条回看整张卡片，`×` 删掉这一条。
8. 卡片页脚会写清楚：类型 · 时间 · 原文多少字 · **用时多少秒** · **token 用量（入/出）** —— 「10 秒内出卡片」这条自己就能核对。
8. **拖文件**：把 `.txt` / `.md` / `.log` / `.json` / `.csv` / `.srt` 之类拖进页面任意位置就能载入（输入框会亮起虚线框提示），拖多个按顺序用空行拼起来；框里已有内容时追加到末尾，不覆盖。单个文件上限 2 MB。
   - 中文 Windows 记事本存的 GBK 文本会自动识别，不乱码
   - 拖图片 / PDF / Word 会被拒并提示「先另存为 .txt」，不会把二进制垃圾塞进输入框

> 粘进去的内容会发到 DeepSeek 服务器。身份证号、银行卡、密码先打码。

## 导入导出文件（这是唯一的数据来源）

只吃**你手动给的导出文件或粘贴内容**，不连任何数据库、不读微信目录、不碰 QQ 本地库。

拖进来（或粘贴）自动识别，认不出就当普通长文本：

| 格式 | 识别依据 | chip 显示 |
|---|---|---|
| 微信 HTML | `class="message"` / `chatlog` 字样 | 微信HTML |
| 微信 CSV | 表头含 `StrTime` / `StrContent` / `NickName` / `Sender` | 微信CSV |
| QQ TXT | 行首 `2026-11-12 14:30:27 昵称(12345)` | QQ TXT |
| QQ MHT | MIME 头 + `quoted-printable`（gb2312 也能解） | QQ MHT |
| 微信「多选→复制」的纯文本 | `昵称  2026-11-12 14:30:27` 或 `昵称：内容` 达到两条以上 | 微信TXT |
| 其它 | — | 通用文本（走原来的长文本流程） |

**chip 就是解析器**：点它换一个，立刻重新解析、统计跟着变。选错了不会把数据弄坏，原始文件内容一直留着。

### 解析结果长什么样

解析完先给你预览，不会直接开炼：

```
微信聊天记录.html   [微信HTML ▾]   移除
识别到 128 条消息 · 3 位参与者 · 11-10 至 11-12
▸ 展开看前 10 条
[ 确认，开始提炼 ]
```

展开后每行是 `时间（原文写法） 发送人 内容`，最多 10 条，多的会注明"还有 N 条（提炼时全部都会带上）"。

解析规则：

- 拆成 **发送人 / 时间 / 内容** 三个字段，缺的就是空，不编
- 连续同一个人、间隔 ≤ 2 分钟、中间没人插话 → **合并成一段**（`mergedCount` 记着合了几条）
- 同一条消息重复出现只留一条（时间戳到分钟级完全相同、或同人同内容 2 分钟内）
- 昵称原样保留，表情和特殊字符不动；群聊里的 `@某人` 原样留着
- 媒体统一成占位：`[图片]` `[表情]` `[语音 3"]` `[文件 报价单.pdf]` `[转账 200 元]` `[视频]` `[位置]` `[名片]`
- 内部时间统一成 `2026-11-12 14:30`（缺日期就留空），但预览里显示的是**原文写法**

### 提炼时的额外规则（提示词里写死的）

| 规则 | 说明 |
|---|---|
| 要点带说话人 | 写「老王要求周六九点前到」，不许写「要求周六九点前到」 |
| 含糊不算定论 | 「应该 / 可能 / 好像 / 我再问问 / 看情况」→ 该条前面挂 **待确认** 标签，同时补一条风险 |
| 相对时间换绝对日期 | 模型照抄「明天 / 周五」，前端按消息最后一天的日期换算成 `周五（11-13）`（正则兜底，不靠模型发挥） |
| 多话题分块 | 一个群同时聊几件事时，多一块「话题分块」，每块 2–8 字小标题 |

相对时间换算规则（基准日 = 导入文件的最后一条消息日期，没有就用今天）：今天/明天/后天/昨天、周X/星期X/本周X/下周X、X 号 / X 日、月底 / 月初。


## 合并转发（v2 新增）

微信 PC 的「合并转发」是卡片消息，右键没有复制，剪贴板里根本拿不到内容。正确姿势：**双击卡片打开独立窗口 → `Ctrl+A` → `Ctrl+C`**，粘进来就是下面这种形态：

```
群聊的聊天记录
[聊天记录]
老王  2026-11-12 14:30:27
快点啊，等半天了，周六九点前要到
小李  2026-11-12 14:31:00
好的
-----原始消息-----
小李  2026-11-12 14:33:00
谢谢，麻烦您了
[完]
```

`parsers/merged-forward.js` 负责识别 + 剥壳：

| 干什么 | 细节 |
|---|---|
| 认出来 | 标题行（`[聊天记录]` / `聊天记录` / `[合并转发]` / `xx和xx的聊天记录`）、分隔符（`-----原始消息-----` / `----------` / `======` / `——— 日期 ———`）任一出现即判定 |
| 剥壳 | 去掉标题、说明行、分隔符、结尾的 `[完]` / `查看更多` / `展开`，去掉多余引号和行首缩进 |
| 嵌套 | 最多向下剥 3 层（转发里套转发），超了就停，不会死循环 |
| 空卡片 | 只有标题没正文时给具体提示，不是"解析失败"：**「请双击卡片打开后 Ctrl+A 全选复制；或点开卡片逐屏截图」** |
| 不误判 | 普通群聊 `昵称: 内容` 单行成条仍判为微信TXT，不会被当成合并转发 |

## 语气 / 身份标注（v2 新增，默认关闭）

开关在「提炼类型」那一行右侧：`● 语气标注`。打开后展开 `仅关键消息 ｜ 全部消息`。

- **只做本地规则推断**（`tone.js`），不发网络请求
- 语气只用固定词表 12 个：催促 / 无奈 / 调侃 / 敷衍 / 确认 / 疑问 / 不满 / 客气 / 急迫 / 犹豫 / 兴奋 / 正式
- 身份只用固定词表 8 个：领导 / 同事 / 客户 / 下属 / 家人 / 朋友 / 陌生人 / 未知（**「未知」不显示**，只留在数据里）
- 证据不足就不标，宁缺勿滥；判定顺序：标点语气词 → 具名表情 → 固定套语 → 句式长度
- 显示成 `（催促）`：12px 浅灰、虚线下边框、鼠标悬停提示「AI 推断，非原文内容」，每条后面带 `×` 可单条删除（删除状态存 `localStorage`，刷新也不会再冒出来）
- 身份标在每个说话人**第一次出现**的位置，一人只标一次
- 关掉开关标注隐藏、数据保留；再打开（除已删的）会回来
- **语气和身份绝不写进卡片正文**：提示词里明确禁止，渲染层也不往四区块里塞

打开语气标注后，导出的提示词长这样（标注在行尾方括号里，明显不是原文）：

```
【消息】
2026-11-12 14:30 老王：快点啊，等半天了，周六九点前要到　〔AI 推断语气：催促〕
2026-11-12 14:31 小李（身份推断：下属）：好的　〔AI 推断语气：确认〕
```

### 表情不再统一成 `[表情]`

`[旺柴]` `[捂脸]` `[裂开]` `[强]` `[微笑]` 这些具名表情**原名保留**（`[动画表情]` 也不动），颜文字 `(￣▽￣)`、`hhh`、`？？？`、`。。。` 原样留着 —— 这些都是判断语气的线索。只有通用占位才归一：`[照片]`→`[图片]`、`[文件]报价单.pdf`→`[文件 报价单.pdf]`、`转账 200 元`→`[转账 200 元]`。


## 交互（卡片里能动手的地方）

| 位置 | 能干什么 |
|---|---|
| 每条要点 / 风险前面的圆圈 | 点一下 = 我理解了，变绿勾 + 前面挂「已知悉」小标签 |
| 每条待办前面的圆圈 | 点一下 = 做完了，整行划掉变灰，卡片顶部徽章同步成 `1/4 项待办` |
| 每条下面的「▸ 原文」 | 展开它依据的原文摘句（默认收起） |
| 每条下面的「问」 | 就地追问这条，只依据原文回答；答不出来会说「原文没写」 |
| 没给出原文的条目 | 会挂一个「未给原文摘句」标签，提醒你这条可能是概括过的 |

勾选状态存在 `localStorage`（`msgcard.marks`），关掉浏览器再打开、从历史里回看都还在；历史记录被删掉时对应勾选一起清掉。

追问是单独一次请求：不带 `json_object`、温度 0.1，system 里明确「只根据原文回答，原文没有就直说没写」。原文最多带 8000 字（`SOURCE_KEEP`）。

## 保真（不让模型糊弄你）

提示词里有三条硬约束，专治"越总结越走样"：

1. **保真优先**：人名、数字、金额、日期、时间、专有名词、承诺性说法必须沿用原文用词 —— 不许换说法、不许取整、不许把「2 万」写成「两万左右」、不许把「周五之前」写成「这周内」。
2. **含糊照抄**：原文自己写得含糊（大概 / 左右 / 看情况 / 暂定），就保留那个含糊词，不许替它补成确定值；同时进「风险与分歧」。
3. **摘句可核对**：每条必须带原文逐字摘句；确实找不到就留空，页面会给这条挂「未给原文摘句」，你就知道这句是模型概括的。

页面上还有一层兜底：**模糊词会被自动标成波浪线（需确认）** —— 大概、大约、左右、若干、可能、估计、差不多、视情况、看情况、暂定、待核实…… 扫一眼就知道哪些数字其实还没落地。

## 重点怎么认（四种标记）

照《四种标记与灰度对照》那套做法：**不靠色相，靠「线型 + 字体 + 形状」三重冗余**，所以黑白打印、色弱、截图转灰之后照样分得清。

| 标记 | 语义 | 视觉手段（去掉颜色也能认） |
|---|---|---|
| 高亮块 `#BA7517` | 核心结论 | 左侧 3px 竖条 + 淡底纹 |
| 波浪线 `#A32D2D` | 需确认（风险 / 未定 / 分歧） | 波浪下划线 + 前方 ▲ 实心三角 |
| 双下划线 `#185FA5` | 硬信息（金额 / 数字 / 编号） | 双下划线 + 等宽字体（金额再带淡蓝底） |
| 虚线下划线 `#3B6D11` | 时间节点 | 点状下划线 + 前方 ○ 空心圆 |
| 划掉 +「已作废」小标签 | 作废掉的待办 | 删除线 + 描边小标签 |

四个区块的左侧色条也换成这四色（结论琥珀 / 信息蓝 / 待办绿 / 风险红），跟行内标记一一对得上。

卡片右上角有 **「灰度自检」** 按钮：点一下整张卡片转灰，就是拿来验上表第三列的。

另外：

- **负责人**仍是橙色小标签；**截止时间**整格加重，写「未定」的灰字虚化
- 标记只改呈现，不改文字；**复制出去的纯文本是干净的**，不带任何标记字符
- 模型输出里就算夹带 HTML 标签，也只当普通文字显示，不会被执行（有自测盯着）
- 相邻的时间词会合并成一个标记（`明天下午 5 点前` 是一个整体，不会插三个圆圈）

## 改提示词

`prompts.js` 里：

- `COMMON` —— 四类内容共用的规则（结论字数、要点条数、`evidence` 必须逐字摘句、待办怎么抓）
- `FOCUS` —— 每种类型的关注点差异
- `SCHEMA` —— 模型必须输出的 JSON 结构。**如果改字段名，`app.js` 里的 `normalizeCard` 要同步改**（它做了容错，但别故意错位）

例子：待办抓漏了，就在 `COMMON` 第 4 条后面加词，比如把「记得」「回头」「别忘了」「X 来跟」都写进触发词里。

## 排错

| 现象 | 原因 |
|---|---|
| 点提炼提示「连不上 DeepSeek」 | 断网 / 防火墙 / 浏览器扩展拦了跨域 |
| 「Key 无效（401）」 | Key 粘错或过期，重新填 |
| 「余额不足（402）」 | 去 platform.deepseek.com 充值、设消费上限 |
| 「返回的不是合法 JSON」 | 模型偶尔跑偏，再点一次即可 |
| 「啥也没提炼出来」 | 文本太短或太碎，或输入框内容没选中类型 |
| 点复制提示「浏览器不让自动复制」 | 极少见，页面会把纯文本摆出来，Ctrl / ⌘ + C 手动拷 |
| 提示「历史存满了」 | 本地存储装不下，已自动丢最旧的记录 |
| 拖文件提示「不是纯文本文件」 | Word / PDF / 图片读不了，另存为 `.txt` 再拖 |
| 拖文件提示「超过 2 MB」 | 单个文件上限 2 MB，切小一点再拖 |



`file://` 直接调 API 的跨域问题已经验证过：DeepSeek 对 `Origin: null` 返回 `access-control-allow-origin: null`，所以不需要本地代理。
