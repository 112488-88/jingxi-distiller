鲸汐提炼器 · 使用说明

一句话：把一段乱糟糟的长消息（群聊、邮件、会议纪要）变成四块卡片，10 秒看完——发生了什么、我要做什么、哪里有坑。

  • 纯前端，双击 index.html 就能用，不装软件、不开服务
  • 零依赖，不连数据库，只读你手动给的导出文件或粘贴内容
  • 唯一对外请求是 DeepSeek 的 deepseek-chat 接口

一、装在哪、怎么打开

想装成 App（推荐）

给它一个 http(s) 地址（GitHub Pages / 自己的服务器 / 局域网都行），打开之后：

  • Chrome / Edge：地址栏右侧出现「安装」图标 → 点一下，装成独立窗口的 App，任务栏/开始菜单有图标
  • 安卓：浏览器菜单里「添加到主屏幕」
  • iPhone：Safari 分享 → 「添加到主屏幕」

装好之后离线也能开（Service Worker 缓存了程序本身；提炼还是要联网调 DeepSeek）。

双击 index.html 的方式依旧可用，只是没有「安装 / 离线」这两项。

Windows 桌面版（exe，不想找浏览器就用这个）

  • 到 Releases 下 鲸汐提炼器-<版本>-便携版.exe（单文件，双击即开，不装运行库）；想要桌面和开始菜单快捷方式就用 -安装版.exe。
  • 独立窗口，任务栏有图标；窗口大小和位置会记住；再点一次图标不会开出第二个。
  • 菜单栏在顶上：文件 / 编辑 / 视图 / 帮助（新建提炼、打印卡片、打开使用说明、打开配置文件夹、缩放、全屏、运行自检都在里面）。
  • 右键有撤销 / 复制 / 粘贴 / 全选这些常用项，Ctrl+P 打印卡片。
  • 觉得哪里不对，菜单「帮助 → 运行自检」会用假数据点一遍主要按钮，跑完自动还原你的数据。
  • 拖文件、导出另存为、复制卡片这些用法和网页版一样（网页版那段 PWA 安装逻辑在桌面版里自动跳过）。
  • Key、历史、桌宠形象存在软件自己的目录 %APPDATA%\鲸汐提炼器\，不再跟着浏览器走；删掉这个文件夹就等于清空。
  • 没买签名证书，第一次双击 Windows 可能提示「未知发布者」→ 点「更多信息」→「仍要运行」，之后不再提示。

所有文件都在 .\。

文件作用能不能删
index.html入口，双击打开不能
style.css样式（深浅色都在里面）不能
app.js界面逻辑、调接口、渲染卡片不能
parse.js聊天记录解析器不能
tone.js语气 / 身份推断不能
parsers/merged-forward.js合并转发外壳剥离不能

README.md技术说明（给我看的）可删
使用说明.md / 使用说明.docx就是这份可删

打开方式：双击 index.html（推荐 Chrome / Edge）。想放桌面就右键 index.html → 发送到 → 桌面快捷方式。

二、第一次使用：三步

第 1 步：拿一个 API Key

打开 https://platform.deepseek.com → 左侧「API keys」→ 创建 → 复制 sk- 开头那串（只显示一次，别关窗口）。

第 2 步：填进工具里

页面右上角点钥匙图标 → 粘贴 → 保存。

  • 保存后右上角变绿点 +「Key 已保存」
  • Key 只存在这台电脑的浏览器里，关掉再开还在
  • 换电脑、换浏览器要重新填

第 3 步：跑一次样例

点页面中间那行小按钮「群聊 · 筹备进度」→ 内容自动填进去 → 点「一键提炼」。

第一次跑大概 3–10 秒。出卡片就说明通了。

提示　别一上来就点「一键提炼」空输入框，会提示你「先粘点东西进来」。

三、四种输入方式

提示　粘贴不会乱改你的类型：只有「真的像聊天记录」（能解析出 2 条以上消息）才会自动变成附件；公文、通知、邮件正文这类会留在输入框里当普通文本，类型自动切到「通用文本」。

提示　你自己点过「邮件 / 会议纪要 / 通用」之后，换解析器、重新解析都不会把它改回去。

提示　另外，点「移除附件」会把原文放回输入框，不会连内容一起清掉。

拖文件把 .html / .csv / .txt / .mht 拖到页面上任何位置微信、QQ 导出的聊天记录

样例点下面的三个小按钮先看手感
纯文本手打/粘贴会议纪要、周报、邮件非聊天内容

认不出格式的，就当普通长文本处理，跟以前一样直接进输入框。

四、支持哪些导出文件（自动识别，不用手选）

来源长得像什么chip 显示
微信 HTML文件里有 class="message" / chatlog微信HTML
微信 CSV表头有 StrTime / StrContent / NickName / Sender微信CSV
QQ TXT行首是 2026-11-12 14:30:27 昵称(12345)QQ TXT
QQ MHT文件里有 MIME-Version + quoted-printableQQ MHT

微信多选复制一行「昵称 + 时间」，下一行内容，成对出现微信TXT
其它—通用文本

识别结果显示在附件那行的 chip 上。chip 就是解析器，点它下拉能换一个，换完立刻重新解析、统计跟着变。

五、合并转发怎么弄（重点）

微信 PC 的合并转发是卡片消息，右键没有「复制」——直接在聊天窗口多选复制，拿到的只有卡片外壳，里面内容根本没进剪贴板。

正确姿势：

  • 1. 双击那个合并转发卡片，弹出独立窗口
  • 2. 窗口里 Ctrl+A 全选 → Ctrl+C 复制
  • 3. 回来 Ctrl+V 粘进工具

粘进来的内容长这样（工具会自动剥壳）：

群聊的聊天记录
[聊天记录]
老王  2026-11-12 14:30:27
快点啊，等半天了，周六九点前要到
小李  2026-11-12 14:31:00
好的
-----原始消息-----
小李  2026-11-12 14:33:00
谢谢，麻烦您了
[完]
  • 标题行、-----原始消息-----、[完] 会被自动去掉，还原成内层对话
  • 转发里套转发也能剥（最多 3 层）
  • 如果只复制到了卡片本身（只有标题没正文），工具会明确告诉你：

提示　这是合并转发的卡片本体，内容不在剪贴板里。请双击卡片打开后 Ctrl+A 全选复制；或点开卡片逐屏截图，把截图一起拖进来。

QQ 复制出来常带 -----原始消息-----，同样处理；破折号分隔线（——— 2026-11-12 ———）也算外壳，一并剥掉。

复制出来的头部格式五花八门，工具都认

不同版本、手机端和 PC 端复制出来的「发送人 + 时间」写法不一样，下面这些都能直接拆：

14:35 老王时分在前
2026-11-12 14:36:00 换行 老王 换行 内容名字单独占一行，会自动补回去
老王： 换行 内容昵称加冒号独占一行（微信多选复制最常见）

认不出来的时候不用猜：附件那行有个 「格式诊断」 按钮，点开能看到

六、解析结果：先预览，再提炼

它不会偷偷丢内容

如果一段文字其实不是聊天记录（通知、公文、制度、邮件正文），哪怕解析器选错了，工具也会：

  • 1. 先算「认出来了多少」；
  • 2. 认出的部分太少（低于 60%）就整段按「通用文本」处理，一个字都不删；
  • 3. 在导入卡片上用黄条告诉你：这段不像聊天记录：按「微信TXT」只认出了 0% 的原文，为了不少内容，已按「通用文本」整段处理（423 字，一个字都没丢）。

宁可少解析几条消息，也不删你的字。

提示　预览是全的：导入多少条就列多少条，每条都显示完整内容，不截字（超过 300 条时才折叠尾部并写明还有几条）。

提示　提炼之后右侧「原文对照」里也是全文，卡片 ⓘ 里还会标「原文 N 字（完整保存）」。

粘/拖进来后不会直接烧 API，先给你看预览：

合并转发.txt   [合并转发 ▾]   移除
识别到 4 条消息 · 2 位参与者 · 11-12
▸ 展开看前 10 条

[ 确认，开始提炼 ]

展开后每行是：原文时间 发送人 内容。最多显示 10 条，多的会写「还有 N 条（提炼时全部都会带上）」。

核对没问题再点「确认，开始提炼」。想换解析器就点 chip。

解析时做的事：

  • 拆成发送人 / 时间 / 内容，缺的就空着，不瞎补
  • 同一个人连续发言、间隔 2 分钟内、中间没人插话 → 合并成一段
  • 重复消息只留一条
  • 媒体统一占位：[图片] [表情] [语音 3"] [文件 报价单.pdf] [转账 200 元]
  • 具名表情原名保留：[旺柴] [捂脸] [裂开] [强] [微笑] 不会变成 [表情]，颜文字、hhh、？？？ 也留着
  • 时间内部统一成 2026-11-12 14:30，预览里显示原文写法（14:30:27）

七、语气标注（可选，默认关）

开关在「提炼类型」那一行右侧：● 语气标注。

点开后：

  • 消息末尾出现浅灰虚线括号 （催促），鼠标悬停提示「AI 推断，非原文内容」
  • 每个说话人第一次出现的位置标身份 （领导） （下属），一人只标一次
  • 每条标注后面有 ×，点掉就不再出现（刷新也不会回来）
  • 下面还能选范围：仅关键消息（默认）/全部消息
  • 关掉开关标注消失，数据还留着，再打开会回来

语气只用固定 12 个词：催促 / 无奈 / 调侃 / 敷衍 / 确认 / 疑问 / 不满 / 客气 / 急迫 / 犹豫 / 兴奋 / 正式。

身份只用固定 8 个：领导 / 同事 / 客户 / 下属 / 家人 / 朋友 / 陌生人 / 未知（「未知」不显示）。

证据不足就不标，宁可空着。语气和身份只出现在预览和提示词里，绝不会写进卡片的结论、关键信息、待办、风险正文。

八、三种类型给出的是三种不同的东西

以前三种类型只有一句「关注点」不同，模型自然只换措辞。现在它们是三种不同的交付物：

类型产出独有内容待办表头
聊天记录聊天要点结论用口语（"老王催周六九点前到，押金还没人认"）；要点带说话人、保留口语；每条待办附原话；多一块「没人回 / 悬空」谁 / 答应了什么 / 截止时间
邮件邮件摘要顶部有抬头（主题/发件人/收件人/抄送/时间）；正文用书面语；多一块「需要你回复的问题」+ 附件清单谁 / 要做什么 / 回复期限
会议纪要会议纪要顶部有会议信息（时间/地点/主持/记录/参会/缺席）；议题按已决·待决·否决标注；多两块「决议」「待决事项（卡在哪、谁继续确认、什么时候）」，再加一行下次会议负责人 / 行动项 / 截止时间
通用文本通用提炼结论 + 要点 + 要做的 + 风险，按原文章节组织负责人 / 事项 / 截止时间

依据：会议纪要按「头部信息 / 议题与结论 / 行动项 / 待决事项」的通用字段结构来写（参考 [ONES 的纪要字段说明](https://ones.cn/blog/knowledge/meeting-minutes-writing-guide-fb81ddd11501e8dd)）；

邮件按「谁发的 → 要我做什么 → 要我回什么」组织；聊天记录按「谁答应了我什么、谁还没回」组织。

九、提炼前：它还会问你有什么要求

原文填进去之后（超过十几个字），要求面板会自己展开，桌宠同时冒一句：「原文够长了，顺手把要求写上？」。

  • 不抢光标：自动展开时焦点还在输入框里，你能继续打字，不会被打断
  • 不烦人：你点过「收起」或「就这些」之后，同一段原文再打字它不会反复弹；清空或换一段新原文才会重新展开
  • 想主动叫出来也行：点右边桌宠，或者它头上的红点。

点它（或者点输入框右下角弹出的面板），可以提要求，这些要求会真的塞进提示词，影响输出：

  • 预设七条，点一下就选中（可多选）：结论再短点 / 正式一点 / 最多 3 条要点 / 金额时间别漏 / 标出我要做的 / 按时间排 / 不要建议
  • 想更细就直接写，例如「结论要能直接转发给领导」「把预算相关的都单独列出来」
  • 点「就这些」→ 提炼按钮会变成「一键提炼（带 N 条要求）」，点下去这些要求会被写进 system 提示词和 user 消息两处
  • 不想提要求就直接点提炼，提示词不会多出任何空段落

提炼完，卡片右上角 ⓘ 里会显示这次是按什么要求做的，方便回头核对。

提示　桌宠默认贴在输入框右侧；拖走之后就停在原地，双击它可以贴回去。

十、卡片怎么读

四块固定顺序：

  • 1. 一句话结论——黄色高亮块，30 字以内
  • 2. 关键信息——3–6 条，每条下面有「▸ 原文」可核对
  • 3. 待办事项——三列表格：负责人 / 事项 / 截止时间
  • 4. 风险与分歧——坑、没定的事、要确认的事
  • 5. （有多个话题时）话题分块——按话题给小标题分组

四种标记怎么看

标记含义长什么样
高亮块核心结论左侧琥珀竖条 + 淡底纹
波浪线 ▲需确认（风险 / 未定 / 含糊）红色波浪下划线 + 三角
双下划线硬信息（金额 / 数字）蓝色双线 + 等宽字体
虚线下划线 ○时间节点绿色点线 + 圆圈

不靠颜色区分，所以黑白打印、截图转灰也分得清。标记说明收在卡片右上角的 ⓘ 里（点开才显示），旁边的「灰度自检」可以一键验证。

另外：

  • 待确认 标签 = 原文只是「应该 / 可能 / 我再问问」这类说法，不是定论
  • 未给原文摘句 标签 = 这条是模型概括的，没有原文可核对，建议点「问」追问
  • 已作废 标签 = 这条被取消了，整行划掉

十一、卡片上能动手的地方

位置点一下会怎样
要点/风险前的圆圈标记「我理解了」，变绿勾 + 「已知悉」
待办前的圆圈标记「做完了」，整行划掉，顶部徽章变 1/4 项待办
▸ 原文展开它依据的原文摘句
问就地追问这一条（只依据原文回答，答不出会说「原文没写」）
卡片顶部 结论 1 / 要点 5 / 待办 3 / 风险 2目录 chips：点一下滚到那一块并闪一下，空块是灰的
ⓘ（卡片右上）展开/收起工程信息（类型、字数、tokens）和标记说明
展开原文（卡片右上）所有摘句一次全开
灰度自检整卡转灰，检查标记是否还认得出
复制卡片（卡片右下）复制成纯文本，粘微信/Word 都行

勾选状态存在本地，刷新、从历史回看都还在。

十、大屏右栏：原文对照

屏幕够宽（≥ 1440px）时，右侧会多出「原文对照」面板，页面变成三栏：

  • 全文：这次导入/粘贴的原文，逐条显示 时间 发送人 内容
  • 大纲：卡片的四个区块，点标题直接滚到那一块
  • 在卡片里点某条的「原文」，右栏会自动切到全文并高亮那一句，方便立刻核对
  • 右上角「收起」可以折叠，折叠状态会被记住；窄屏（笔记本 1080p、手机）自动隐藏，不占地方

提示　这块只是把核对成本降到零，不改任何提炼结果。

十三、桌宠：小鲸汐

左下角那条小鲸鱼是个能问话的助手。它不会自己动你的数据，只做两件事：读原文、回答你的问题。

动作结果
自动提炼完成后它会说「读完了，问我吧」，此时它手里就是这次的原文
点它一下弹出对话面板，顶上写着它读到了多少字、几条消息
输入问题比如「押金多少钱、谁交、什么时候交」，它只按原文回答，原文没写就直说没写
拖着走按住能拖到任意位置，位置会记住（下次打开还在那儿）
顶栏小鲸鱼按钮藏起来 / 叫回来，状态会记住
闲置 90 秒它会闭眼打盹（zzz），动一下鼠标就醒
Esc先收对话面板；再按才动附件

它和卡片里每条下面的「问」是同一套提示词（只依据原文、数字照抄、原文没写就说没写），区别是：卡片里的「问」针对某一条，桌宠针对整段原文。

提示　每次问它都会把原文一起发出去（和提炼时一样），所以别把不该外发的原文喂给它。

它还能帮你存文件

面板里有一排小按钮，点一下就把当前卡片落成文件：

按钮存出来的是用途

文件存到哪？

  • 浏览器支持「另存为」时（Chrome / Edge），会弹出保存对话框，你可以直接选桌面；
  • 不支持或没弹窗时，退回到浏览器默认下载文件夹（一般在「下载」里）。

提示　浏览器网页没有权限直接往任意路径写文件、也没法操作别的程序 —— 这就是网页能做到的上限：生成文件 + 让你选存哪。真要「自动放进 D 盘某个文件夹」，得装桌面端。

换个形象

点面板里的「形象」：

  • 三个内置：小鲸汐 / 小海猫 / 小水母，点一下立刻换，眼睛照样跟着鼠标转
  • 想用自己的图，三种上传方式任选：
  • 1. 点「上传图片」，选一张图
  • 2. 把图片直接拖到左下角的桌宠身上（拖到上面会提示「松手换形象」）
  • 3. 复制一张图，页面上按 Ctrl + V 粘贴
  • 规格建议：正方形、透明背景 PNG，256×256 就够，最大 3 MB；GIF 动图也能用，会自己动
  • 大图会自动等比缩到 512 以内再存，不占地方
  • 「恢复默认」回到小鲸汐

图片只存在你这台电脑的浏览器里（localStorage 优先，IndexedDB 兜底），不会上传到任何服务器。

十五、提炼规则：能保证什么

  • 要点带说话人：写「老王要求周六九点前到」，不写「要求周六九点前到」
  • 含糊不算定论：说「应该」「可能」的，会被标成 待确认 并额外进一条风险
  • 时间换绝对日期：原文的「明天 / 周五 / 下周一」会按消息最后一天换算成「周五（11-13）」
  • 保真：人名、数字、金额、时间照抄原文，不许取整、不许换说法
  • 可追溯：每条要点配原文摘句；给不出的会标「未给原文摘句」

十六、隐私和成本

  • 只有你粘/拖进来的原文会发给 DeepSeek，工具本身不收集任何东西
  • 涉密内容、身份证号、银行卡号、密码，先打码再粘
  • deepseek-chat 很便宜，一次提炼几分钱；卡片右下角会显示本次 tokens，自己心里有数
  • 记得去 DeepSeek 平台设置消费上限

十八、它不能做什么（已知限制）

  • 不吃截图：多张滚动截图的 OCR 拼接没做（要塞十几 MB 的 OCR 引擎，跟"双击即用"冲突）。截图请自己转成文字，或用第五节的全选复制
  • 不连数据库：不读微信 / QQ 本地聊天库，只认你给的文件和粘贴内容
  • 格式有版本差异：微信不同版本、手机端和 PC 端复制出来的格式不完全一样。遇到解析不出来的，把那段原文发我，我加进解析规则
  • 质量取决于原文：原文含糊，卡片也只能反映含糊（会标出来，不会替它编）

二十、想自己验一遍

工具自带 105 项自动化自测（用无头浏览器跑，不花 API 额度）：

node selftest.mjs

全绿就是功能都正常，截图和报告会落在同目录。

手工验收只需要四条：

  • 1. 填 Key → 点一个样例 → 10 秒内出四块卡片
  • 2. 拖一个微信 HTML 进去 → chip 显示「微信HTML」，条数对得上
  • 3. 复制一段合并转发 → 粘进来 → chip 显示「合并转发」，发送人还原出来
  • 4. 打开「语气标注」→ 消息后面出现 （催促） 这类括号，点 × 能删掉

有任何一条对不上，就把原文、截图或控制台报错发我，我按你那条改。
